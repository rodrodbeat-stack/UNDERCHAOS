# CYBERREELS — SKYNET SOCIAL

Plantilla de red social cyberpunk responsive, lista para GitHub Pages.

## Archivos
- `index.html`: estructura y contenido.
- `styles.css`: diseño visual, paneles, responsive y efectos.
- `app.js`: interacciones de demostración.

## Publicar en GitHub Pages
1. Sube los tres archivos a la raíz de tu repositorio.
2. En GitHub entra a **Settings → Pages**.
3. En **Build and deployment**, selecciona `Deploy from a branch`.
4. Selecciona `main` y `/ (root)`, guarda y espera el despliegue.

## Personalización
- Cambia `darkcode_2050`, nombres, textos y productos desde `index.html`.
- Las imágenes de demostración se cargan desde Unsplash y requieren conexión a internet.
- La publicación y el chat funcionan en el navegador como demo local. Para persistencia multiusuario, autenticación, comentarios reales y subida de medios hay que conectar un backend (por ejemplo Supabase).
